# 🕷️ Spider-Verse Apparel & Gear | Spider-Man Themed E-Commerce Store

An ultra-premium, highly animated Spider-Man themed product store built purely with **HTML5 and CSS3** (Vanilla web technologies).

## 🚀 Key Features

- **🕸️ Canvas Web-Drawing Preloader**: Dynamic SVG & Canvas animation that draws a spiderweb on initial page loading.
- **🕷️ Swinging Spider Widget**: Interactive swinging Spider-Man fixed to the top right.
- **⚡ Cyber Glitch & Neon Hero Section**: Cyber-glitch text effects, glowing orbit rings, and floating canvas particles.
- **🛍️ Product Showcase Grid**: Interactive product cards featuring Spider-Man masks, tech jackets, graphic tees, stainless steel bottles, web shooters, and action figures.
- **🔥 Animated Ticker & Floating Elements**: Smooth glowing badges, glowing buttons, and hover tilt effects.
- **📱 Fully Responsive**: Custom CSS layout that looks awesome across mobile, tablet, and desktop viewports.

## 🛠️ Built With

- **HTML5**
- **CSS3** (Keyframes, CSS Variables, Flexbox & CSS Grid)
- **Vanilla JS** (Embedded canvas particle system & preloader trigger)

## 📁 How to View

Simply double-click `index.html` or open it in any modern web browser (Edge, Chrome, Firefox, Safari, Brave). No server setup or dependencies required!
